# Гео-эмбеддинги

Мультимодальные векторные представления географических локаций для многопрофильных downstream задач. Позволяют объединить признаки географических объектов в универсальный вектор для повторного использования в прикладных задачах, что позволяет экономить время на сбор данных и анализ признаков, а также добавлять дополнительный географический контекст для повышения точности предсказаний. 

Является развитием проекта https://github.com/InfinitasFish/geo_embeddings

Для запуска сервиса на устройстве с GPU выполните следующую команду:

```docker compose -f docker-compose.gpu.yaml -f docker-compose.yaml up -d --build```

Для запуска на устройстве без GPU - сдедующая команда:

```docker compose -f docker-compose.yaml up -d --build```

**Документация по API укзана в файле [api.md](api.md)**

Пример использования сервиса путем обращения к нему представлен в файле `decode_example.py`

Переменные окружения (указываются в файле `.env`, жирным шрифтом выделены обязательные переменные):

- **HF_TOKEN**=токен HuggingFace для выгрузки моделей
- **HF_BEST_REPO_ID**=ID репозитория HuggingFace для выгрузки моделей
- TOCHNO_ST_BASE_LINK=базовая ссылка для загрузки датасетов по муниципальным образованиям
- MUN_GEOMS_LINK=ссылка на загрузку границ муниципальных образований
- CHECK_PEOPLE_WORKPLACES_TASKS=проверка на коммерческих данных (предоставляются по запросу)

- HOST=хост веб-приложения
- PORT=порт веб-приложения

- DB_HOST=хост СУБД Postgres для хранения геометрии территорий
- DB_PORT=порт СУБД Postgres для хранения геометрии территорий
- DB_NAME=имя СУБД Postgres для хранения геометрии территорий
- **DB_USER**=пользователь СУБД Postgres для хранения геометрии территорий
- **DB_PWD**=пароль СУБД Postgres для хранения геометрии территорий

- INIT_EMBEDDINGS=формировать векторные представления на основе муниципальных данных при запуске контейнера или ожидать данные от пользователя

- QDRANT_HOST=хост базы хранения эмбеддингов
- QDRANT_PORT=порт базы хранения эмбеддингов
- QDRANT_API_KEY=API-ключ базы хранения эмбеддингов (по умолчанию - пустая строка)

Чтобы не проводить эксперименты самостоятельно, можно воспользоваться сохраненными эмбеддингами и чекпоинтом модели. Для этого можно указать ```HF_BEST_REPO_ID=smthrgnl/geo_embeddings_model``` и собственный токен аутентификации.

Ссылка на репозиторий HuggingFace: https://huggingface.co/smthrgnl/geo_embeddings_model.
В репозитории хранятся чекпоинты и эмбеддинги всех протестированных моделей и файл `best_embedding_summary.json`, в котором указано, какая модель и какие эмбеддинги являются лучшими по результатам экспериментов - использоваться будут они.

Для воспроизведения экспериментов:

- Если указана переменная `CHECK_PEOPLE_WORKPLACES_TASKS=true`, то переменные `PEOPLE_FEATURES`,
`PEOPLE_CAT_FEATURES`, `WORKPLACES_FEATURES`, `WORKPLACES_CAT_FEATURES` также должны быть заполнены. Они необходимы для тестирования на коммерческих датасетах и предоставляются по запросу, сервис способен функционировать без них.
